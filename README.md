# Quality MSA — Dashboard de Qualidade Industrial

## Sobre o projeto

O **Quality MSA** é um dashboard desenvolvido para auxiliar no acompanhamento de indicadores de qualidade e produção industrial, centralizando informações importantes em uma interface visual, intuitiva e de fácil utilização.

A proposta é facilitar o monitoramento dos resultados da produção, a identificação de perdas e o acompanhamento de peças, contribuindo para uma tomada de decisão mais rápida e eficiente.

## Objetivos

* Centralizar indicadores de qualidade e produção.
* Facilitar o acompanhamento das peças produzidas e aprovadas.
* Monitorar peças descartadas e perdas durante o processo produtivo.
* Acompanhar o cumprimento das metas diárias de produção.
* Visualizar a quantidade de peças que estão em inspeção.
* Apoiar a identificação de problemas e oportunidades de melhoria.

## Funcionalidades

* **Indicadores de qualidade:** cálculo do percentual de peças aprovadas em relação ao total produzido.
* **Meta diária de produção:** acompanhamento da quantidade produzida em relação à meta estabelecida, com indicador de progresso.
* **Peças descartadas:** visualização das perdas e dos itens rejeitados durante a produção.
* **Peças em inspeção:** acompanhamento das peças que aguardam ou estão passando por inspeção de qualidade.
* **Perdas de produção:** organização das perdas relacionadas ao início da operação e ao processo produtivo.
* **Visualização de dados:** apresentação dos indicadores por meio de gráficos, barras de progresso e elementos visuais.

## Tecnologias utilizadas

* HTML5 — estruturação da interface.
* CSS3 — estilização, layout e responsividade.
* JavaScript — cálculos, atualização dos indicadores e interatividade.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/thaisferreira-moura/quality_msa.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd quality_msa
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
